# 项目范围

## 1. 当前定位

当前尚未签订合作合同，也没有确定具体场景。核电和风电是两个候选合作方向，不是计划同时交付的两个产品。当前保留两套资料，是为了：

- 提前理解行业基本结构。
- 判断不同方向可能涉及的知识和数据。
- 具备与行业专家讨论大模型项目的能力。
- 在合作方向明确后更快进入需求阶段。

合作确定后：

1. 只保留选择领域的入门、术语和来源资料。
2. 删除另一领域的项目内容。
3. 由合作方专业人员明确业务场景。
4. 我方根据场景形成数据需求。
5. 合作方按照其专业规范和现有条件交付数据。

## 2. 当前资料

文档重点是：

- 行业对象如何组织。
- 行业数据之间如何关联。
- 哪些数据对大模型项目真正有用。
- 不同场景适合什么技术路线。
- 与行业专家合作时容易产生哪些误解。

## 3. 当前阶段产出

- 核电项目导向的入门材料。
- 风电项目导向的入门材料。
- 两个领域的术语速查。
- 官方权威资料入口。
- 核电与风电 AI 合作、落地状态及候选场景调研。
- 核电与风电公开数据、合作方数据及模型影响调研。
- 公共的模型路线判断。
- 场景确定后使用的数据需求和交付说明模板。

## 4. 当前阶段不做

- 数据采集、接入和清洗。
- 合作方数据治理设计。
- 固定数据格式和字段 Schema。
- 额外的场景管理和验收体系。
- 模型训练和技术选型。

## 5. 后续工作边界

合作方负责：

- 明确业务场景和专业目标。
- 解释业务流程、专业术语和数据语义。
- 按其内部规范确认和交付数据。
- 对专业结论和标签负责。

我方负责：

- 将场景转成可执行的模型任务。
- 明确实现任务所需的数据范围。
- 对交付数据进行清洗、关联和建模。
- 建立基线、评测并选择 RAG、微调或专属模型。
- 将模型输出设计成适合专业人员使用的形式。

双方的接口主要是“场景、数据需求、数据交付和专业确认”，不需要由本项目预先规定合作方的内部流程。
