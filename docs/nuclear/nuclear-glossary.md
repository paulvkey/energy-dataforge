# 核电术语速查

以下释义用于项目沟通入门，不替代法规、标准或设计文件中的正式定义。建议先阅读[核电大模型项目入门](nuclear-primer.md)，遇到正式术语再查阅 [IAEA Safety Glossary（PDF）](https://www.iaea.org/sites/default/files/17/11/iaea-safety-glossary-rev2016.pdf) 或 [NRC 核能术语表](https://www.nrc.gov/reading-rm/basic-ref/glossary/full-text)。

| 术语 | 英文/缩写 | 项目中的简要理解 |
|---|---|---|
| 同位素 | Isotope | 质子数相同、中子数不同的原子 |
| 核裂变 | Nuclear Fission | 重原子核分裂并释放能量和中子的过程 |
| 链式反应 | Chain Reaction | 裂变释放的中子继续引发其他裂变 |
| 临界 | Criticality | 链式反应能够稳定维持的反应堆物理状态，不等于事故边缘 |
| 衰变热/余热 | Decay Heat | 停堆后裂变产物衰变继续产生的热量 |
| 热功率 | Thermal Power, MWth | 反应堆产生热量的速率 |
| 电功率 | Electric Power, MWe | 发电机输出电功率 |
| 发电量 | Electrical Energy, MWh/GWh | 一段时间累计产生的电能 |
| 贝可 | Becquerel, Bq | 每秒发生一次核衰变的活度单位 |
| 戈瑞 | Gray, Gy | 物质单位质量吸收辐射能量的剂量单位 |
| 希沃特 | Sievert, Sv | 考虑辐射类型和生物影响的剂量单位 |
| 核电厂 | Nuclear Power Plant, NPP | 利用核能产生电力的设施 |
| 机组 | Unit | 通常指一套相对独立的反应堆及发电系统 |
| 压水堆 | Pressurized Water Reactor, PWR | 一回路水在高压下带走堆芯热量的常见堆型 |
| 沸水堆 | Boiling Water Reactor, BWR | 冷却剂在反应堆内产生蒸汽的堆型 |
| 堆芯 | Reactor Core | 燃料组件等构成、发生裂变并产生热量的区域 |
| 核岛 | Nuclear Island, NI | 包含反应堆及重要核安全相关系统的厂房和设施集合 |
| 常规岛 | Conventional Island, CI | 主要包含汽轮机、发电机等常规发电系统 |
| 一回路 | Primary Circuit | 从堆芯带走热量的反应堆冷却剂回路 |
| 二回路 | Secondary Circuit | 在蒸汽发生器获得热量并驱动汽轮机的回路 |
| 反应堆压力容器 | Reactor Pressure Vessel, RPV | 容纳堆芯和反应堆冷却剂的重要设备 |
| 蒸汽发生器 | Steam Generator, SG | 将一回路热量传给二回路并产生蒸汽 |
| 反应堆冷却剂泵 | Reactor Coolant Pump, RCP | 推动一回路冷却剂循环，常称主泵 |
| 稳压器 | Pressurizer | 调节压水堆一回路压力的重要设备 |
| 控制棒 | Control Rod | 通过吸收中子等作用调节反应性 |
| 安全壳 | Containment | 包容和防护的重要实体屏障 |
| 纵深防御 | Defence in Depth | 通过多层、相互补充措施降低风险 |
| 安全功能 | Safety Function | 为实现核安全目标所需的功能 |
| 安全系统 | Safety System | 执行或支持安全功能的系统 |
| 冗余 | Redundancy | 通过多个通道或设备提高功能可靠性 |
| 多样性 | Diversity | 使用不同原理或方式降低共因失效风险 |
| 独立性 | Independence | 降低系统、通道或功能之间的不利相互影响 |
| 运行事件 | Operating Event | 运行中出现并按规定记录、分析或报告的事件 |
| 经验反馈 | Operating Experience Feedback, OEF | 将事件、偏差和行业经验用于持续改进 |
| 国际核与辐射事件分级表 | INES | 用于沟通核与辐射事件安全意义的分级工具 |
| 核安全导则 | Safety Guide | 为满足安全要求提供方法和建议的文件类别 |
| 最终安全分析报告 | Final Safety Analysis Report, FSAR | 描述设施设计、安全分析等的重要文件 |
| 技术规格书 | Technical Specifications | 规定相关运行限制、条件和监督要求的文件 |
| 工况 | Operating Condition | 设备或机组所处的运行状态和条件 |
| 停堆 | Reactor Shutdown | 反应堆停止维持功率运行的状态或过程 |
| 换料大修 | Refuelling Outage | 换料并集中开展检修试验的停机窗口 |
| 预防性维修 | Preventive Maintenance | 为降低失效概率按计划开展的维护 |
| 纠正性维修 | Corrective Maintenance | 针对已发现故障或缺陷开展的维修 |
| 状态监测 | Condition Monitoring | 利用测量和分析判断设备状态 |
| 测点 | Measurement Point/Tag | 传感器或系统中的具体信号标识 |
| 采样频率 | Sampling Frequency | 传感器或系统记录数据的时间间隔 |
| 质量码 | Quality Code | 表示测量值是否有效、替代、异常或通信中断的代码 |
| 报警 | Alarm | 提示状态达到预设条件的信号 |
| 联锁 | Interlock | 为防止不允许状态或动作而设置的逻辑 |
| 保护信号 | Protection Signal | 触发保护动作或相关逻辑的信号 |
| 根本原因分析 | Root Cause Analysis, RCA | 系统分析事件深层原因的方法 |
| 概率安全分析 | Probabilistic Safety Assessment, PSA | 使用概率方法评估风险的分析 |
| 确定论安全分析 | Deterministic Safety Analysis, DSA | 基于规定事件、假设和准则的安全分析 |
| 容量因子 | Capacity Factor | 实际发电量与同期间持续额定功率发电量之比 |
| 可用因子 | Availability Factor | 机组可用于发电时间或能力的统计指标，具体口径需确认 |

## 使用注意

- 相同缩写在不同组织中可能有不同含义。
- 中英文翻译应优先沿用适用法规、标准和合作方术语库。
- 技术规格、保护设定值和详细安全分析不属于入门材料范围。
- 术语表需要由核电领域人员在签约后复核。
