# 核电公开来源规划

## 1. 当前状态

本文件只登记候选公开来源，当前不下载。以后只有在确定场景确实需要时才采集，并保留来源、版本和用途信息。

## 2. 来源优先级

### A 级：国内法律与监管机构

| 候选来源 | 可了解内容 | 初步路线 |
|---|---|---|
| [国家核安全局](https://nnsa.mee.gov.cn/) | 法规标准体系、监管信息、运行事件、年报 | 元数据登记；RAG 候选 |
| [生态环境部](https://www.mee.gov.cn/) | 法律政策、环境影响评价、辐射环境信息 | 元数据登记；RAG 候选 |
| [国家能源局](https://www.nea.gov.cn/) | 能源政策和电力统计 | 结构化查询/RAG 候选 |
| [国家原子能机构](https://www.caea.gov.cn/) | 原子能政策、国际合作和科普信息 | 内部学习/RAG 候选 |
| [国家法律法规数据库](https://flk.npc.gov.cn/) | 法律法规正式文本与状态 | RAG 候选 |

### B 级：国际组织和境外监管机构

| 候选来源 | 可了解内容 | 使用注意 |
|---|---|---|
| [IAEA](https://www.iaea.org/) | 安全标准、术语、报告、数据库 | 逐项确认版权；标注国际组织来源 |
| [IAEA PRIS](https://pris.iaea.org/pris/) | 全球核电机组和统计信息 | 记录更新时间、字段定义和使用条款 |
| [美国 NRC](https://www.nrc.gov/) | 公开监管文件和运行经验 | 明确美国司法辖区，不作为中国法规结论 |
| [OECD NEA](https://www.oecd-nea.org/) | 核能政策、技术与安全报告 | 逐项确认访问与版权条件 |

### C 级：行业组织、企业和科研机构

仅用于补充背景或发现线索。正式使用前需验证：

- 是否为机构正式发布。
- 是否引用更高等级原始来源。
- 是否存在商业宣传或特定技术路线偏差。
- 是否允许复制、索引、训练和对外交付。

## 3. 首批建议登记的资料类别

1. 核安全法律法规层级和现行目录。
2. 国家核安全局年度报告。
3. 国家核安全局公开运行事件。
4. IAEA 安全标准分类和术语。
5. PRIS 公开机组字段和统计口径。
6. 核电基础科普和监管体系说明。

## 4. 暂不纳入

- 论坛、自媒体和无法追溯原始来源的转载。
- 未经授权的标准全文、教材扫描件和商业数据库。
- 可能暴露内部系统、参数、图纸或薄弱点的资料。
- 为采集而绕过登录、访问控制或技术限制的内容。

## 5. 后续采集前只确认五件事

1. 对应哪个已确定场景。
2. 从哪个官方页面获得。
3. 文件是什么版本、是否仍有效。
4. 页面或文件允许如何使用。
5. 采集结果如何服务当前模型任务。
