# 风电公开来源规划

## 1. 当前状态

本文件只登记候选公开来源，当前不执行下载或接口调用。以后只有在具体场景需要时才采集。

## 2. 来源优先级

### A 级：国内政府与公共机构

| 候选来源 | 可了解内容 | 初步路线 |
|---|---|---|
| [国家能源局](https://www.nea.gov.cn/) | 政策、装机、发电和行业统计 | 结构化查询/RAG 候选 |
| [国家标准信息公共服务平台](https://std.samr.gov.cn/) | 标准题录、状态和替代关系 | 元数据优先；全文逐项审查 |
| [中国气象数据网](https://data.cma.cn/) | 地面气象、气候和相关数据产品 | 专属模型/分析候选 |
| [国家统计局](https://www.stats.gov.cn/) | 宏观统计与统计口径 | 结构化查询候选 |

### B 级：国际组织与国家实验室

| 候选来源 | 可了解内容 | 使用注意 |
|---|---|---|
| [Copernicus Climate Data Store](https://cds.climate.copernicus.eu/) | ERA5 等再分析数据 | 标记为再分析；记录许可和版本 |
| [Global Wind Atlas](https://globalwindatlas.info/) | 全球风资源空间信息 | 适合初步资源研究，不是现场实测 |
| [NREL Wind Research](https://www.nrel.gov/wind/) | 风电研究、工具和公开数据 | 记录覆盖区域、模型和使用条款 |
| [IRENA](https://www.irena.org/) | 可再生能源统计和报告 | 逐项确认统计口径和许可 |

### C 级：行业组织、厂商和研究论文

用于补充行业背景、技术路线和术语，但需要：

- 区分厂商宣传、行业统计和技术事实。
- 追溯到原始数据或正式报告。
- 记录机型、区域、时间和方法适用范围。
- 单独确认论文、图表、数据附件和标准的使用许可。

## 3. 首批建议登记的资料类别

1. 国内风电政策、装机和发电统计。
2. 风电国家标准和行业标准题录。
3. 气象数据产品说明及变量定义。
4. ERA5 数据说明、许可和引用要求。
5. Global Wind Atlas 数据性质和许可。
6. NREL WIND Toolkit 数据结构和适用范围。
7. 风机基础结构和功率曲线科普资料。

## 4. 暂不纳入

- 来源不明的场站坐标、机组清单和功率数据。
- 未经授权的商业风资源数据库。
- 厂商内部手册、告警码和控制策略。
- 将模拟或再分析数据表述为现场实测的二手数据。
- 通过绕过登录、额度或访问控制进行批量采集。

## 5. 后续采集前只确认六件事

1. 对应哪个已确定场景。
2. 数据来自哪个官方页面。
3. 时间范围、空间范围和分辨率是什么。
4. 是观测、再分析、预测、模拟还是推导数据。
5. 页面或数据允许如何使用。
6. 采集结果如何服务当前模型任务。
